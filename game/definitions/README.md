# Contenido

## cgs.rpy
Este archivo define todas las imágenes de evento (CGs) de tu juego.

## definitions.rpy
Este archivo define el código, la música, las variables e imágenes de tu juego.

## effects.rpy
Este archivo define los efectos visuales especiales de tu juego.

## splash.rpy
Este archivo almacena la splash screen, el código del menú principal y más.

## transforms.rpy
Este archivo define todas las transiciones y animaciones del juego.

## menu_screens.rpy
Este archivo define los menús (principal, de pausa y quick menu), configurables por el modder.

## persistent.rpy
Este archivo define las variables persistentes (se guardan entre partidas).

## music.rpy
Este archivo define la música y los efectos de sonido.

## sprites.rpy
Este archivo define los sprites de los personajes (im.Composite, sistema Bronya).
