# Contenido de la carpeta `mod_assets`

Esta carpeta almacena todas tus imágenes, música/sfx y más relacionadas con tu juego.

## Carpeta `audio`
Guarda aquí tu música (`.ogg`) y efectos de sonido. Las rutas que declares en
`definitions/music.rpy` apuntan aquí, ej:
    define audio.t1 = "<loop 22.073>mod_assets/audio/music/1.ogg"

## Carpeta `images`
Guarda aquí tus fondos, sprites, logo, CGs y demás imágenes. Las rutas que
declares en `definitions/definitions.rpy` y `definitions/splash.rpy` apuntan aquí.
